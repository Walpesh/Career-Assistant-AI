# Career-Assistant-AI — Общее описание, стек и KPI

## 1. Общее описание продукта

**Career-Assistant-AI** — коммерческий веб-сервис для автоматизации поиска, парсинга, анализа вакансий с hh.ru и генерации персонализированных сопроводительных писем с помощью LLM.

Сервис полностью работает без официального API hh.ru (API для соискателей закрыт с декабря 2025 года).

### Основные принципы
- Реал-тайм отображение всех процессов через WebSocket
- Максимальная устойчивость к блокировкам и капче hh.ru
- Модульная архитектура (Modular-Flow)
- Приоритет на локальную LLM (Ollama) + возможность подключения внешних LLM API
- Полная привязка всех данных к конкретному пользователю

### Ключевые возможности
- Три режима сбора вакансий: Автопоиск, Групповой парсер, Ручное добавление
- Четыре режима обработки: Только Анализ / Только Письмо / Анализ + Письмо / AUTO (с матчингом)
- Умный парсинг только необходимой информации (шапка + описание)
- Персонализированный анализ соответствия и генерация сопроводительных писем
- Полноценный раздел «Анализ и Отклик» для работы со всеми вакансиями пользователя

## 2. Стек технологий

### Frontend
- HTML5 + CSS3 + JavaScript
- Tailwind CSS
- WebSocket (реал-тайм)
- Кастомный компонент Fadeout-action-popup

### Backend
- FastAPI (Python 3.12+)
- PostgreSQL
- Redis (очереди задач + кэширование)
- Playwright + playwright-stealth / Patchright / Nodriver
- curl_cffi (основной быстрый HTTP-клиент с имитацией TLS-fingerprint)

### LLM
- Ollama (основной / developer-режим)
- Поддержка внешних LLM API (в качестве опции)

### Очереди и асинхронность
- Redis + ARQ (реализовано: очереди `career:queue:parsing` и `career:queue:llm`, см. docs/04 §6)
- Строгая последовательная очередь для всех запросов к LLM

## 3. Ключевые KPI продукта

| Метрика | Целевое значение | Комментарий |
|---------|------------------|-----------|
| Успешность парсинга | ≥ 95% | При соблюдении лимитов и использовании резидентных прокси |
| Время полного цикла (парсинг → анализ → письмо) | ≤ 45 секунд | На одну вакансию при использовании Ollama |
| Объём обработки | 300–500 вакансий / сутки | На одного пользователя без риска бана |
| Время отклика интерфейса | < 200 мс | На любые действия пользователя (кроме долгих операций) |
| Доступность реал-тайм канала | ≥ 99% | Стабильность WebSocket-соединения |

## 4. Модель разработки

**Modular-Flow** — модульная архитектура с чёткими границами ответственности и единым потоком данных между модулями.

Основные модули:
- Auth & User
- User Profile («Моё резюме»)
- Parsing Orchestrator
- Proxy & Anti-Ban
- Vacancy Storage
- Queue Manager
- Analysis & Letter
- Realtime & Notification
- Privacy (выгрузка и удаление персональных данных)
- Billing (тарифы, суточные квоты, платёжные вебхуки)
- Health & Metrics (readiness-проверки, Prometheus-метрики, алерты)
