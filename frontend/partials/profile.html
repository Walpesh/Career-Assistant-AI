Хотите добавить информацию в конец резюме?

0 / 2000

Если поле заполнено, текст автоматически дописывается в конец каждого сопроводительного письма с новой строки — скриптовым методом, без участия нейросети. Пустое поле — ничего не добавляется.

Навыки

Enter, запятая или точка с запятой — добавить. Backspace в пустом поле — удалить последний.

Опыт и зарплатные ожидания

Порог матчинга

70%

В режиме AUTO сопроводительное письмо создаётся, только если match_score ≥ порога. Для остальных режимов порог — справочный.
