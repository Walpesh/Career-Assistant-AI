1. Общие положения

Career-Assistant-AI (далее — «Сервис») — веб-приложение для автоматизированного сбора публичных вакансий с сайта hh.ru, анализа соответствия резюме кандидата и генерации сопроводительных писем с помощью языковой модели. Используя Сервис, пользователь принимает настоящие Условия и обязуется соблюдать их.

Сервис предоставляется на безвозмездной основе на тарифе Free либо на платных тарифах Pro и Enterprise. Перечень и стоимость тарифов, а также суточные лимиты операций опубликованы на экране профиля и в разделе Billing.

2. Регистрация и доступ

  • Для использования требуется аккаунт, созданный по адресу электронной почты.
  • Пользователь обязуется указать достоверные данные и не передавать их третьим лицам.
  • Все действия внутри аккаунта считаются действиями пользователя, включая действия автоматизированных сценариев, запущенных из его сессии.
  • Пользователь самостоятельно обеспечивает конфиденциальность средств доступа; при подозрении на компрометацию обязан сменить пароль.

3. Автоматический сбор вакансий: оговорка и риски

Сервис работает без официального API hh.ru: API для соискателей закрыт с декабря 2025 года, поэтому вакансии собираются автоматически — с публичных страниц сайта, через резидентные прокси, с имитацией поведения реального пользователя (ротация IP, человеческие паузы, прогрев сессии).

Пользователь принимает и подтверждает следующее:

  • Сервис не связан с hh.ru и не представляет его. Товарные знаки и содержание вакансий принадлежат их правообладателям; Сервис лишь отображает их для личного использования.
  • Автоматизированный сбор может нарушать условия использования hh.ru. Пользователь решает сам, допустимо ли это в его целях и для его аккаунта, и несёт связанные риски, включая ограничение или блокировку доступа на стороне площадки.
  • Сервис не обходит авторизацию и не получает доступ к закрытым персональным данным: собираются только публично доступные страницы вакансий.
  • Собранные данные предназначены для личного использования кандидатом и не подлежат перепубликации, коммерческой перепродаже или массовой перепродаже баз вакансий.
  • Скорость сбора технически ограничена (паузы 4–8 секунд между запросами, не более 60–80 запросов с одного IP-адреса) для снижения нагрузки на площадку.

4. Обязанности пользователя

  • Не использовать Сервис для сбора персональных данных других лиц.
  • Не предпринимать действий по обходу суточных лимитов тарифа.
  • Не размещать в поле резюме сведения, не имеющие отношения к поиску работы, а также данные, распространение которых нарушает законодательство.
  • Не использовать автоматизированные сценарии для массового создания аккаунтов или перепродажи доступа.

5. Оплата и возврат

Оплата платных тарифов производится через платёжного оператора (ЮKassa, CloudPayments или Stripe). Тариф активируется автоматически после подтверждения платежа оператором: факт оплаты подтверждается только серверной проверкой подписанного уведомления, направленного на защищённый адрес Сервиса.

Возврат средств производится по обращению в службу поддержки в течение 14 календарных дней с даты оплаты при условии, что услуги Сервиса фактически не оказывались либо вопрос технического характера не может быть устранён силами пользователя.

6. Интеллектуальная собственность

Исключительные права на Сервис, его интерфейс и документацию принадлежат правообладателю. Тексты резюме, вакансий и сгенерированных писем остаются данными пользователя; их дальнейшее использование определяется законодательством и правами соответствующих правообладателей.

7. Ограничение ответственности

Сервис предоставляется «как есть». Разработчик не гарантирует бесперебойной работы, полноты и точности данных, а также сохранность результатов при сбоях. Ответственность разработчика ограничена стоимостью оплаченной пользователем услуги.

8. Изменение условий

Разработчик вправе изменять Условия. Новая редакция вступает в силу с момента публикации на этой странице. Продолжение использования Сервиса после публикации изменений означает согласие с ними.
